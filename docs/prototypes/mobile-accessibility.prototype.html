Throwaway interaction prototype · proposed behavior

One session, two ways to place a bet

Can you select, edit, and inspect the same wagers through a graphical table and a readable selector, including on a narrow screen with large text? This demo uses a few fixed examples; it does not deal cards, run a game, or save data.

The text toggle illustrates reflow. Native VoiceOver, TalkBack, switch control, display scaling, and maximum system text sizes still need testing on actual devices.
